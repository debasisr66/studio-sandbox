# Studio sandbox (throwaway preview)

A throwaway copy of [Studio](https://github.com/debasisr66/studio) for testing changes on a phone **before** they are merged. It is **not** the real site.

- Built by `scripts/make-sandbox.js` in the Studio repository; the page title starts with "SANDBOX".
- Its admin publishes to **this** repository only. Use a separate fine-grained token limited to this repository, never the real Studio token.
- Nothing here is authoritative. Anything in this repository can be overwritten at any time.
